# Buvette-Gestion

A web app for managing a school cafeteria (buvette). Built with CodeIgniter 4 and PHP.

Handles things like product listings, stock tracking, and basic sales management. It was a school project, so nothing too complex, but it works end-to-end.

## Setup

Make sure you have PHP 8.1+ and Composer installed.

`ash
composer install
cp env .env
# Edit .env to set your database credentials and base URL
php spark serve
`

The app will run at http://localhost:8080.

## Requirements

- PHP 8.1 or higher
- MySQL
- Composer
- Extensions: intl, mbstring, mysqlnd
